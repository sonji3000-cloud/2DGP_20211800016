소닉 애니메이션 뷰어 작성

개발언어 python
라이브러리 pcio2d
파일이름 sonic_animation_viewer.py
단일 파일로만 작성함.
스프라이트 이미지는 sonic-sprite.png


기능
이미지의 모든 동작을 재생.
동작별 5회 재생, 1초 쉬고, 그다음 동작 재상.
모든 동작을 다 재생한 후, 다시 무한 반복

2·5·6·7번째 줄의 동작은 애니메이션과 함께 화면 위치도 이동.
화면 경계에서는 진행 방향과 캐릭터 방향을 함께 반전.
3·8·9번째 줄은 화면 중앙에서 제자리 재생. 8번째 줄의 점프도 화면 위치는 고정.
동작별 5회 재생 후 1초 쉬는 동안 마지막 프레임과 위치, 방향을 유지.
새 동작은 화면 중앙에서 오른쪽 방향으로 시작.

한 줄에 여러 애니메이션이 있으므로 다음 범위는 각각 별도 동작으로 재생.
첫 줄: 1~7번은 대기, 8~11번은 하나의 별도 동작이며 모두 제자리 재생.
8번째 줄: 1~6번과 7~8번을 분리. 두 동작 모두 제자리 재생.
마지막 줄: 1~2번과 3~4번을 각각 별도 포즈로 제자리 재생.
총 13개 애니메이션, 원본 76프레임을 누락·중복 없이 사용.
분리된 각 동작에도 5회 재생 후 1초 정지를 개별 적용.

화면 대비, 이미지가 잘 보이게 충분히 확대


개발 방법:
한번에 다 개발하지 말고, 단계별로 구현해서ㅜ, 커밋을 그때그때 할 수 있도록
최소한 개발단계는 20단계 이상으로 한다
