# 소닉 애니메이션 뷰어 개발 문서

## 1. 목적과 결과물

`sonic-sprite.png`에 들어 있는 소닉의 모든 동작을 차례대로 보여 주는 뷰어를 만든다. 각 동작을 5회 재생하고 마지막 프레임을 1초간 유지한 뒤 다음 동작으로 넘어간다. 마지막 동작이 끝나면 첫 동작부터 다시 무한 반복한다.

걷기·달리기처럼 이동이 포함된 동작은 프레임 재생과 동시에 화면 위치도 움직인다. 점프는 수평 이동에 포물선 높이 변화를 더하며, 동작 사이의 정지 중에는 프레임·위치·방향을 함께 유지한다.

| 항목 | 결정 사항 |
| --- | --- |
| 작업 위치 | `Labs/LEC09/` |
| 구현 언어와 라이브러리 | Python, `pico2d` |
| 실행 파일 | `sonic_animation_viewer.py` 한 파일 |
| 이미지 자산 | 같은 폴더의 `sonic-sprite.png` |
| 스프라이트 시트 크기 | 399×525px |
| 기본 캔버스 | 1200×600px |
| 기본 표시 배율 | 원본 프레임의 4배, 가로세로 비율 유지 |

`PRE_PRD.md`의 `pcio2d`는 기존 수업 예제와 강의 자료의 표기를 근거로 `pico2d`의 오타로 해석한다. 캔버스 크기와 4배 배율은 “이미지가 잘 보이게 충분히 확대”를 검증 가능한 수치로 구체화한 기본값이다.

## 2. 스프라이트 범위와 프레임 데이터

- 시트의 제목, 크레딧, 제작자 그림 및 빈 여백은 재생 대상에서 제외한다. 소닉의 동작을 이루는 프레임은 빠짐없이 포함한다.
- 프레임은 `(left, bottom, width, height)`로 기록하고, `pico2d`의 이미지 좌표계에 맞춰 시트의 아래쪽을 원점으로 사용한다. 시트를 위에서부터 조사할 때는 `bottom = 525 - top - height`로 변환한다.
- 동작마다 프레임 목록과 순서를 명시한다. 간격이 불규칙하거나 프레임 크기가 달라도 각 프레임의 좌표를 개별적으로 저장한다. 숫자 간격만 가정해 잘못된 영역을 자르지 않는다.
- 모든 프레임은 시트 경계 안에 있어야 하며, 이웃한 동작·문자·배경 여백이 잘려 들어오지 않아야 한다. 투명 여백이 필요한 경우에는 동작의 위치가 흔들리지 않도록 기준점을 함께 조정한다.
- 원본 시트의 **10개 행·76프레임**을 **13개 애니메이션**으로 나눈다. 한 행이 반드시 하나의 동작을 뜻하지 않는다. 첫 행은 1~7번과 8~11번, 8행은 1~6번과 7~8번, 10행은 1~2번과 3~4번으로 구분한다. 각 범위 안에서는 왼쪽부터 재생하며, 원본 프레임을 누락·중복 없이 사용한다.

## 3. 기능 요구사항

### FR-1. 실행과 자산 로드

`Labs/LEC09`에서 `sonic_animation_viewer.py`를 실행하면 캔버스가 열리고 같은 폴더의 스프라이트 시트를 한 번 로드한다. 실행 중 경로 오류가 나지 않도록 이미지 경로는 스크립트 위치를 기준으로 계산한다.

### FR-2. 프레임 표시

현재 동작의 프레임을 등록된 순서대로 한 장씩 그린다. 화면은 약 60회/초를 목표로 지우고 다시 그려, 같은 애니메이션 프레임을 표시하는 동안에도 위치를 연속적으로 갱신한다. 기본 출력은 원본 프레임의 4배이며, 프레임 전체가 캔버스 안에 보여야 한다. 배경과 캐릭터가 구분되도록 단색 배경을 사용한다.

### FR-3. 동작별 반복과 전환

한 동작의 첫 프레임부터 마지막 프레임까지 재생하는 것을 1회로 정의한다. 한 동작을 정확히 5회 재생한 뒤 그 동작의 마지막 프레임·위치·방향을 1초간 유지한다. 이후 다음 동작을 화면 중앙 `(600, 300)`에서 오른쪽 방향으로 시작한다. 프레임 재생 속도는 코드 상수로 관리하고, 초기값은 프레임당 0.1초로 둔다. 실제 시각 검증 결과에 따라 동작별로 조정할 수 있다.

### FR-4. 전체 순환

등록된 모든 동작을 고정된 순서로 재생한다. 마지막 동작의 5회 재생과 1초 정지가 끝나면 첫 동작으로 돌아간다. 중간에 빈 화면이나 의도하지 않은 추가 정지가 없어야 한다.

### FR-5. 종료

창 닫기 요청을 받으면 재생을 멈추고 캔버스를 정상적으로 닫는다. 반복 재생 중에도 종료 입력을 처리한다.

### FR-6. 이동과 방향 전환

시트의 행을 기준으로 아래 이동 설정을 적용한다. 동작 이름은 뷰어에서 사용하는 분류이며 프레임 순서는 기존 시트 순서다.

| 시트 행 | 프레임 범위 | 동작 분류 | 프레임 수 | 가로 속도(px/초) | 점프 높이(px) |
| ---: | --- | --- | ---: | ---: | ---: |
| 1 | 1~7 | 대기 | 7 | 0 | 0 |
| 1 | 8~11 | 대기 별도 동작 | 4 | 0 | 0 |
| 2 | 1~12 | 달리기 | 12 | 240 | 0 |
| 3 | 1~6 | 질주 | 6 | 320 | 0 |
| 4 | 1~9 | 회전 진입 | 9 | 0 | 0 |
| 5 | 1~6 | 구르기 | 6 | 220 | 0 |
| 6 | 1~6 | 회전 달리기 | 6 | 260 | 0 |
| 7 | 1~6 | 고속 회전 달리기 | 6 | 340 | 0 |
| 8 | 1~6 | 점프 | 6 | 160 | 120 |
| 8 | 7~8 | 공중 자세 | 2 | 0 | 0 |
| 9 | 1~8 | 걷기 변형 | 8 | 120 | 0 |
| 10 | 1~2 | 포즈 A | 2 | 0 | 0 |
| 10 | 3~4 | 포즈 B | 2 | 0 | 0 |

표의 각 항목을 독립적으로 5회 재생하고 1초 정지한다. 첫 행의 8~11번은 네 프레임을 묶은 하나의 동작이다.

- 이동량은 실제 경과 시간과 속도로 계산한다. 프레임 전환 간격인 0.1초 사이에도 이동하며, 화면 갱신 횟수에 따라 속도가 달라지지 않는다.
- 각 동작은 중앙에서 오른쪽으로 시작한다. 같은 동작의 5회 반복 사이에는 가로 위치와 진행 방향을 이어 간다.
- 확대된 동작의 최대 프레임 너비를 기준으로 좌우에 20px 이상의 여백을 둔다. 경계에 닿으면 남은 이동 거리를 반사하고, 왼쪽으로 진행할 때 스프라이트를 좌우 반전한다.
- 점프는 한 번의 프레임 시퀀스마다 시작 높이에서 출발해 중간에 120px 상승하고 다시 내려오는 포물선으로 표현한다. 5회 재생 동안 점프도 5회 반복한다.
- 첫 행의 두 동작, 4행, 8행의 7~8번, 10행의 두 포즈는 중앙에 고정한다. 모든 동작은 1초 정지 중 위치와 방향이 바뀌지 않아야 한다.

## 4. 구현 구조

구현 코드는 `sonic_animation_viewer.py` 한 파일에 둔다. 프레임 좌표와 동작 순서는 데이터로 선언하고, 프레임 그리기·한 동작 재생·전체 순환을 각각 함수로 분리한다. 화면 위치와 배율, 프레임 시간, 반복 횟수, 동작 간 정지 시간은 파일 상단 상수로 관리한다. 이미지 파일과 이 문서는 코드 파일 수 제한에 포함하지 않는다.

원본 행별 좌표는 `SPRITE_ROWS`에 저장한다. `ANIMATION_SPECS`는 각 동작의 이름·행·첫 프레임·마지막 프레임·이동 설정을 함께 선언하며, 여기서 `ANIMATIONS`와 `MOTIONS`를 생성한다. 동작을 분리할 때 프레임과 이동 설정이 서로 어긋나지 않도록 한다. `motion_pose()`가 경과 시간으로 위치와 방향을 계산하고, `play_animation()`이 프레임 전환과 이동을 같은 시간 기준으로 갱신한다. `draw_frame()`은 계산된 위치와 방향을 받아 그린다.

## 5. 완료 기준과 확인 방법

1. `Labs/LEC09`에서 실행했을 때 이미지가 로드되고 소닉이 확대되어 선명하게 보인다.
2. 스프라이트 시트의 모든 소닉 동작과 프레임이 프레임 목록에 포함되며, 제목·크레딧은 표시되지 않는다. 13개 동작·76프레임이며, 분할 전후의 원본 프레임과 순서가 동일하고 누락·중복이 없어야 한다.
3. 각 동작의 프레임 순서가 자연스럽고, 잘못 잘린 프레임이나 캔버스 밖으로 나가는 프레임이 없다.
4. 각 동작은 정확히 5회 재생되고, 마지막 프레임을 유지한 채 1초 후 다음 동작으로 넘어간다.
5. 마지막 동작 이후 첫 동작으로 돌아가고, 최소 두 번의 전체 순환 동안 재생이 이어진다.
6. 재생 도중 창을 닫으면 프로그램이 종료된다.
7. 구현 과정을 최소 20개의 작은 개발 단계로 나누고, 각 단계의 변경과 확인 결과를 커밋으로 남긴다.
8. 이동 동작 7종은 같은 프레임을 표시하는 동안에도 위치가 변하고, 경계에서 방향과 그림이 함께 반전되며 화면 밖으로 나가지 않는다.
9. 점프는 이동과 동시에 상승·하강한다. 첫 행의 두 동작, 회전 진입, 별도 공중 자세, 마지막 행의 두 포즈는 중앙에 고정된다.
10. 1초 정지 중에는 마지막 프레임·위치·방향이 유지된다. 재생 중과 정지 중 모두 창 닫기 또는 Esc로 종료할 수 있다.

## 7. 확인이 필요한 세부 사항

사용자가 확인한 분할 범위를 기준으로 13개 동작과 76프레임을 사용한다. 동작 이름은 표시된 자세를 구분하기 위한 이름이며, 추가 분류 수정 시 `ANIMATION_SPECS`와 위 표를 함께 갱신한다. 프레임당 적정 재생 시간은 시각 확인 결과에 따라 조정할 수 있다.
