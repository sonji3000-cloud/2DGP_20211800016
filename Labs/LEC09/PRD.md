# 소닉 애니메이션 뷰어 개발 문서

## 1. 목적과 결과물

`sonic-sprite.png`에 들어 있는 소닉의 모든 동작을 차례대로 보여 주는 뷰어를 만든다. 각 동작을 5회 재생하고 마지막 프레임을 1초간 유지한 뒤 다음 동작으로 넘어간다. 마지막 동작이 끝나면 첫 동작부터 다시 무한 반복한다.

| 항목 | 결정 사항 |
| --- | --- |
| 작업 위치 | `Labs/LEC09/` |
| 구현 언어와 라이브러리 | Python, `pico2d` |
| 실행 파일 | `sonic_animation_viewer.py` 한 파일 |
| 이미지 자산 | 같은 폴더의 `sonic-sprite.png` |
| 스프라이트 시트 크기 | 399×525px |
| 기본 캔버스 | 1200×600px |
| 기본 표시 배율 | 원본 프레임의 4배, 가로세로 비율 유지 |

`PRE_PRD.md`의 `pcio2d`는 기존 수업 예제와 강의 자료의 표기를 근거로 `pico2d`의 오타로 해석한다. 캔버스 크기와 4배 배율은 “이미지가 잘 보이게 충분히 확대”를 검증 가능한 수치로 구체화한 기본값이다.

## 2. 스프라이트 범위와 프레임 데이터

- 시트의 제목, 크레딧, 제작자 그림 및 빈 여백은 재생 대상에서 제외한다. 소닉의 동작을 이루는 프레임은 빠짐없이 포함한다.
- 프레임은 `(left, bottom, width, height)`로 기록하고, `pico2d`의 이미지 좌표계에 맞춰 시트의 아래쪽을 원점으로 사용한다. 시트를 위에서부터 조사할 때는 `bottom = 525 - top - height`로 변환한다.
- 동작마다 프레임 목록과 순서를 명시한다. 간격이 불규칙하거나 프레임 크기가 달라도 각 프레임의 좌표를 개별적으로 저장한다. 숫자 간격만 가정해 잘못된 영역을 자르지 않는다.
- 모든 프레임은 시트 경계 안에 있어야 하며, 이웃한 동작·문자·배경 여백이 잘려 들어오지 않아야 한다. 투명 여백이 필요한 경우에는 동작의 위치가 흔들리지 않도록 기준점을 함께 조정한다.
- 강의 자료에 제시된 **10종 동작·총 76프레임**을 전체 등록 목표로 삼는다. 구현 전 프레임 목록을 이미지와 대조해 동작 경계와 실제 좌표를 확정한다. 이름이 불명확한 동작은 시트의 위쪽부터 순서대로 식별자를 붙이고, 확인 후 의미 있는 이름으로 바꾼다.

## 3. 기능 요구사항

### FR-1. 실행과 자산 로드

`Labs/LEC09`에서 `sonic_animation_viewer.py`를 실행하면 캔버스가 열리고 같은 폴더의 스프라이트 시트를 한 번 로드한다. 실행 중 경로 오류가 나지 않도록 이미지 경로는 스크립트 위치를 기준으로 계산한다.

### FR-2. 프레임 표시

현재 동작의 프레임을 등록된 순서대로 한 장씩 그린다. 매 프레임마다 화면을 지우고 새 프레임을 그린 뒤 화면을 갱신한다. 기본 출력은 원본 프레임의 4배이며, 프레임 전체가 캔버스 안에 보여야 한다. 배경과 캐릭터가 구분되도록 단색 배경을 사용한다.

### FR-3. 동작별 반복과 전환

한 동작의 마지막 프레임 뒤 첫 프레임으로 돌아가는 것을 1회 재생으로 정의한다. 한 동작을 정확히 5회 재생한 뒤 그 동작의 마지막 화면을 1초간 유지한다. 이후 다음 동작의 첫 프레임을 표시한다. 프레임 재생 속도는 코드 상수로 관리하고, 초기값은 프레임당 0.1초로 둔다. 실제 시각 검증 결과에 따라 동작별로 조정할 수 있다.

### FR-4. 전체 순환

등록된 모든 동작을 고정된 순서로 재생한다. 마지막 동작의 5회 재생과 1초 정지가 끝나면 첫 동작으로 돌아간다. 중간에 빈 화면이나 의도하지 않은 추가 정지가 없어야 한다.

### FR-5. 종료

창 닫기 요청을 받으면 재생을 멈추고 캔버스를 정상적으로 닫는다. 반복 재생 중에도 종료 입력을 처리한다.

## 4. 구현 구조

구현 코드는 `sonic_animation_viewer.py` 한 파일에 둔다. 프레임 좌표와 동작 순서는 데이터로 선언하고, 프레임 그리기·한 동작 재생·전체 순환을 각각 함수로 분리한다. 화면 위치와 배율, 프레임 시간, 반복 횟수, 동작 간 정지 시간은 파일 상단 상수로 관리한다. 이미지 파일과 이 문서는 코드 파일 수 제한에 포함하지 않는다.

## 5. 완료 기준과 확인 방법

1. `Labs/LEC09`에서 실행했을 때 이미지가 로드되고 소닉이 확대되어 선명하게 보인다.
2. 스프라이트 시트의 모든 소닉 동작과 프레임이 프레임 목록에 포함되며, 제목·크레딧은 표시되지 않는다. 등록 결과를 10종·76프레임 목표와 대조한다.
3. 각 동작의 프레임 순서가 자연스럽고, 잘못 잘린 프레임이나 캔버스 밖으로 나가는 프레임이 없다.
4. 각 동작은 정확히 5회 재생되고, 마지막 프레임을 유지한 채 1초 후 다음 동작으로 넘어간다.
5. 마지막 동작 이후 첫 동작으로 돌아가고, 최소 두 번의 전체 순환 동안 재생이 이어진다.
6. 재생 도중 창을 닫으면 프로그램이 종료된다.
7. 구현 과정을 최소 20개의 작은 개발 단계로 나누고, 각 단계의 변경과 확인 결과를 커밋으로 남긴다.
